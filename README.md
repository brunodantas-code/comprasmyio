# Purchase Order Hub

preciso criar um sistema de pedidos de compra de material. Tem a visão do usuário que pede o material, ele precisa setar o nome do projeto, o nome do item e o link do item. 
ele tem em outra aba a visualização do status do pedido de compra. Ele pode botar os pontos de entrega desse pedido do material. 
o admim cria os projetos e pode analisar tudo o que acontece, logs... 
a visão do Comprador é quem recebe os pedidos ( como comprar), ele muda o status como comprado, aguardando, a caminho, cancelado e chegou no destino... 
ele tem a possibilidade de adicionar campo de observação nesse pedido, em determinadas situações o entregador exige a palavra passe e precisa estar escrito nessas observações
