---
name: Etiquetas do Supply
description: Etiqueta opcional e única nas solicitações Internas; criação só Admin, Financeiro e Compras
type: feature
---
- Etiquetas identificam projetos internos (feiras, novas tecnologias) para consolidar custo total.
- Só em alocação Interna, opcional, uma por solicitação.
- Criar/editar/excluir: Admin, Financeiro e Compras. Etiqueta usada é inativada, nunca apagada.
- Cadastro → Etiquetas mostra criador. Relatório de custo por etiqueta fica em Todos os Approvals (botão de tela + ícone PDF), nunca no Cadastro.
