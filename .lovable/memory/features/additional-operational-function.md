# Função operacional adicional

O cargo principal continua sendo a única referência para hierarquia e alçadas. A função operacional adicional é independente e não inclui o usuário na cadeia de aprovação.

Inicialmente, a função disponível é **Time de Supply**, representada pelo papel `comprador`. Ela concede acesso operacional à Fila do Supply, alertas e atualização do andamento da compra. Usuários cujo cargo principal contém “Supply” continuam reconhecidos da mesma forma.
