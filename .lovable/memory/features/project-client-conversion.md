---
name: Conversão de projeto em cliente
description: Projeto só vira Cliente após implantação e contrato assinado; Novo Projeto não permite escolher Cliente
type: feature
---
- O formulário de Novo Projeto não possui campo Cliente.
- Um Projeto só pode virar Cliente depois de implantado e com contrato assinado.
- Até essas duas condições serem atendidas, Projeto e Cliente permanecem cadastros distintos.
- Na integração externa, quando a conversão for válida, o nome do Projeto continua sendo enviado no campo `nome_cliente`.
